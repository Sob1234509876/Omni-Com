Omni Com OC/1

浏览器客户端：一个 WebSocket，一行一条命令，一个回答。

操作说明：协议面板提供 PING、COUNT、REGISTER、 LOGIN、REQ engine-info、REQ hello 与 QUIT；下面的 「游戏操作」面板会发送 WHOAMI、ORDER、BUILD 与 TRAIN，这些游戏命令会改变服务器上的世界（WHOAMI 只登记身份）。页面不会 修改服务器配置或插件状态；所有游戏命令都要求先在同一条连接上 LOGIN。 REGISTER 只在服务器上创建账号，不会自动登录，也不改已有账号。

命令

REQ 要求先在同一条连接上成功 LOGIN； engine-info 的请求与回答外面还有一层 AES-256-GCM 信封，密钥就是上面的 debug.key。hello 是示例插件 oc-hello 的普通 UTF-8 请求，没有信封：页面把名字编码成 UTF-8、base64 后发送，再把回答的 base64 解码成文本。

游戏操作

选中自己（HUD 中的玩家 id）的单位后可用

TRAIN

BUILD

左键点选，Shift+左键加减选单个单位，空地左键拖拽框选自己的单位；右键对所有选中单位发 ORDER MOVE（目标是敌方实体时发 ORDER ATTACK），STOP 停止所有选中单位。 BUILD 按钮进入放置模式后，鼠标下的建筑足迹会先按格预览：绿色可建造、红色被地形/实体/窗口阻挡、 琥珀色超出工兵 16 格范围；只有绿色位置才会发 BUILD，非法位置保持放置模式并报告原因， Esc 取消放置。左下角小地图显示已载入窗口，左键点击或拖动可移动镜头。

engine-info 使用浏览器 WebCrypto；请用 http://127.0.0.1:25567/ 或 HTTPS 打开页面。普通 HTTP 的局域网 IP 不是安全上下文，crypto.subtle 不可用。
